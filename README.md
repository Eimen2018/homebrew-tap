# homebrew-tap

Homebrew tap for my macOS apps.

## [Lonar](https://github.com/Eimen2018/lonar)

Sync external monitor brightness with your MacBook's built-in display.

```bash
brew install --cask eimen2018/tap/lonar
```

Updates: Lonar updates itself via Sparkle (`auto_updates true`), or
`brew upgrade --cask lonar`.

## [Monnect](https://github.com/Eimen2018/monnect)

Switch a Magic Mouse and Keyboard between two Macs from the menu bar — no
cable, no KVM. (Installs [blueutil](https://github.com/toy/blueutil) as a
dependency.)

```bash
brew install --cask eimen2018/tap/monnect
```

Updates: `brew upgrade --cask monnect`.
